# 🎓 AI Attendance System using Face Recognition

A smart attendance system developed using **Python**, **Streamlit**, **OpenCV**, and **Face Recognition**. The system automatically detects students from classroom images or a live camera feed and marks attendance with confidence scores.

---

## 📌 Features

- 🔐 Teacher Login
- 📷 Upload Classroom Images
- 📸 Live Camera Capture
- 😀 Face Recognition
- ✅ Automatic Attendance
- 📊 Attendance Dashboard
- 💾 Save Attendance to CSV
- 🗄 Store Attendance in SQLite Database
- 🎯 Confidence Score Display
- 📥 Download Attendance Report

---

## 🛠 Technologies Used

- Streamlit

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Attendance-System.git
```

### Move into Project

```bash
cd AI-Attendance-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Project

```bash
streamlit run app.py
```
